# Lucas Pereira — Portfólio

Código-fonte do portfólio de Lucas Pereira, estudante de Análise e Desenvolvimento de Sistemas (4º ciclo) na Fatec Praia Grande.

**Site publicado:** https://lucas-pereira-portfolio-three.vercel.app

## Conteúdo

- `index.html`: estrutura do site, conteúdo profissional e apresentação de seis projetos reais.
- `styles.css`: visual "painel de partidas" (quadros de aço, placas de virar, status por borda).
- `app.js`: títulos em células, animação de virada e filtro de projetos (melhoria progressiva).
- `fonts/`: fonte Saira hospedada no próprio site (licença OFL em `fonts/OFL.txt`).
- `favicon.svg`, `cv.pdf`: ícone e currículo.
- `vercel.json`: cabeçalhos de segurança (CSP restrita, sem recursos de terceiros).
- `PRODUCT.md`, `DESIGN.md`, `CLAUDE.md`: fatos do produto, sistema visual e guia para manutenção.

Site estático em HTML, CSS e JavaScript puro, sem framework e sem etapa de build: basta abrir `index.html` ou servir a pasta com qualquer servidor estático.

Os sistemas internos apresentados no portfólio não têm código nem credenciais neste repositório. O código público do Ponto Líder está em [LucasPereiraa18/ponto-lider](https://github.com/LucasPereiraa18/ponto-lider).

## Publicação

O projeto na Vercel não está ligado a este repositório: commits aqui **não** atualizam o site automaticamente. A publicação é feita manualmente com a Vercel CLI.
